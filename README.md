# 🐦 Flappy Bird (Python + Pygame)

### Clean Gameplay • Smooth Physics • Rain Animation After Game Over

A beautifully polished **Flappy Bird clone** built using **Python Pygame** with smooth bird physics, animated pipes, clean UI, and a unique **rain-birds effect** shown after Game Over.
The game gets harder as you score more, making it challenging and fun.

This project includes:

🎮 Smooth Jump Controls
🐦 Custom Bird Design
🟩 Animated Pipes
⚡ Auto Difficulty Increase
🌧 Rain Birds After Game Over
🏆 Score System
💥 Collision Detection
🔄 Press R to Restart
⛔ ESC to Quit Anytime

---

## 🚀 Game Features

### 🐤 Smooth Bird Physics

* Gravity-based motion
* Space key to flap (jump)
* Soft and realistic movement

### 🟩 Pipes System

* Pipes spawn continuously
* Random gap positions
* Difficulty increases:

  * **Pipe speed increases**
  * **Gap size reduces** after score 5

### 🌧 Rain-Bird Effect (Unique Feature!)

After Game Over:

* 45 mini birds fall from the top
* Continuous raining animation
* Smooth and colorful
* Makes Game Over screen visually beautiful

### 💥 Collision Detection

* Bird hits pipe → **Game Over**
* Bird touches top/bottom screen → **Game Over**
* Restart without closing the game

## ▶ How the Game Works

* Bird starts in the middle
* Press SPACE to jump
* Pipes move from right to left
* Bird must pass through the gap
* Score increases after passing each pipe
* At score 5:

  * Pipe speed increases
  * Pipe gap decreases
* Collision triggers Game Over
* Rain birds animation plays
* Press R to restart instantly
